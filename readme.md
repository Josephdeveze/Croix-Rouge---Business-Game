# Site Web de la Croix-Rouge Française - Cagnes-sur-Mer

## Description
Site web officiel de l'antenne locale de la Croix-Rouge Française à Cagnes-sur-Mer. Ce site présente les services, activités et opportunités de bénévolat proposés par notre unité locale.

## Fonctionnalités

### Pages principales
- Accueil avec présentation des services clés
- Actions et services proposés
- Page de dons en ligne
- Histoire de l'organisation
- Formulaire de contact
- Section recrutement

### Services présentés
- Secours d'urgence
- Aide alimentaire
- Boutique solidaire  
- Formation aux premiers secours

## Technologies utilisées
- HTML5
- CSS3
- Bootstrap 3.0
- jQuery
- Font Awesome
- Google Maps API
- Headroom.js

## Installation
1. Cloner le repository
2. Ouvrir index.html dans un navigateur web
